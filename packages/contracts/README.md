# @figloom/contracts

Versioned Zod schemas and shared wire types for Figloom verification requests, artifacts, dashboard projections, and live progress events.

```ts
import {
  verificationRequestSchema,
  verificationArtifactSchema,
  visualScoreArtifactSchema,
} from "@figloom/contracts";
```

This package has no dependency on capture, comparison, server, or UI code.
